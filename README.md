# AI漫剧编剧人格测试

> 课题：大众对 AI 漫剧剧情桥段偏好的测试与分析

假如你是 AI 漫剧编剧，凭第一直觉选出你会写的剧情方案。30 道题做完，系统会告诉你最像哪一种创作者、最匹配哪一个题材赛道，并把匿名数据沉淀下来做可视化统计分析。

**纯原生实现**：HTML + CSS + 原生 JavaScript，零依赖、零构建、可离线运行。

## 四大创作风格（人格维度）

用作**风格参考**，不是给人贴标签——每个人通常是多种风格的混合。

| 代号 | 名称 | 一句话画像 |
|---|---|---|
| ⚔️ F | 宿命史诗派 | 「天道不公，我便逆天而行。」宏大叙事、使命感、名场面运镜 |
| 🤪 M | 抽象整活派 | 「家人们谁懂啊。」无厘头设定、打破第四面墙、高密度玩梗 |
| 🌀 T | 狗血反转派 | 「你以为这是结局？不，这只是第三集。」身世之谜、悬念钩子 |
| 🍲 W | 温情治愈派 | 「没事，慢慢来，饭在锅里。」日常细节控、烟火气美学 |

另有 **40 个 AI 漫剧题材标签**（女频 20 + 男频 20，如「重生复仇」「签到系统流」「种田养娃」「末日囤货生存」），每个标签都带有主类型 `main` 与副类型 `sub`。

## 题库构成

| | 情景题（测人格） | 题材题（定标签） | 合计 |
|---|---|---|---|
| 题库总量 | 100 | 200 | **300** |
| 每轮抽取 | 10 | 20 | **30** |

设计约束：

- 每题 4 个选项**恰好**对应 F / M / T / W 各一个，计分完全对称，不存在位置偏差
- 题材题选项的选项类型恒等于该标签的 `main` 类型
- 同一主类型下的标签出现次数均衡，避免冷热门标签的结构性偏差：

  | 主类型 | 标签数 | 每个标签出现次数 |
  |---|---|---|
  | F | 14 | 14 ~ 15 |
  | M | 10 | 20 |
  | T | 8 | 25 |
  | W | 8 | 25 |

- 全题库共 1200 个选项位，其中互不重复的选项文本 1014 条

## 抽题是真随机

`Math.random()` 是引擎内置的伪随机算法（V8 为 xorshift128+），输出由内部状态递推而来、理论上可预测，不适合需要公平性的抽题场景。本项目改用浏览器 CSPRNG：

```js
function randomInt(max) {
  const bound = Math.floor(0x100000000 / max) * max;  // 拒绝采样的接受区上界
  const buf = new Uint32Array(1);
  let v;
  do { CRYPTO.getRandomValues(buf); v = buf[0]; } while (v >= bound);
  return v % max;
}
```

三步设计：

1. **真随机源**：`crypto.getRandomValues()`，由操作系统熵池提供随机数
2. **拒绝采样**：丢弃落在「2³² 最后一个不完整 max 区间」的取值，消除 `% max` 带来的取模偏差，`[0, max)` 内每个整数概率严格相等
3. **分层配额 + 拒绝重抽**：情景题层取 10 道、题材题层取 20 道，层内为等概率无放回随机子集；若抽到的一组包含重复题干或重复选项文字，则整组重抽。**这样既保证每题概率严格均等，又保证每次测试的题型配比稳定**（否则某次只抽到 6 道题材题，标签判定会失真）

Fisher–Yates 洗牌、选项顺序打乱同样走这条链路。

## 计分与匹配算法

**人格计分**：某题的某个类型有 `n` 个选项时，选中该类型得 `1/n` 分——使随机作答对每个类型的期望收益完全相同，避免选项分布造成偏差。主类型取最高分者，平票时取更靠后作答的那一题所属类型（更接近「事后直觉」）。

**标签匹配**：综合三项加权得到契合度 `fit`：

```
fit = 0.45 × 类型契合度(余弦) + 0.35 × 直接命中率 + 0.20 × 频道契合
```

- 类型契合度：用户四维得分向量与标签的「主类型 0.65 + 副类型 0.35」向量的余弦相似度
- 直接命中率：`该标签被选次数 / 该标签在题库中的出现次数`（除以出现次数以消除冷热门标签的曝光差异）
- 频道契合：用户的女频 / 男频倾向与标签所属频道的一致性

输出 TOP 5 标签排序，并给出四派风格百分比与女频 / 男频倾向。
